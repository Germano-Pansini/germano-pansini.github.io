with a focus on real-time perception, edge deployment, and autonomous systems.

## Scope

This website collects:
- Research activities and publications
- Robotics and computer vision projects
- Media demos (videos, posters)
- Academic and professional résumé

Content is written in Markdown and rendered into a lightweight static site.

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- Markdown-based content
- GitHub Pages hosting

## Structure

- docs/index.html – Main page
- docs/about.md – About & selected projects
- docs/publications.md – Publications
- docs/resume.md – Résumé
- docs/news.md – Timeline & updates
- docs/assets/images/ – Images and posters
- docs/assets/videos/ – Video demos
- docs/assets/pdf/ – Certificates and thesis PDFs
- docs/styles.css – Styling
- docs/script.js – Client-side functionality
