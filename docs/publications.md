# Publications

## Crop Monitoring via Deep-Learning-Based Pest Classification for Pesticide Reduction

**IEEE International Humanitarian Technologies Conference (IHTC), 2024**

Antonello Longo, Maria Rizzi, Pierluigi Longo, **Germano Pansini**, Cataldo Guaragnella

<img src="assets/images/IHTC.png" alt="IHTC 2024 — Pest Detection Pipeline" style="width:100%; max-width:720px; border-radius:16px; border:1px solid var(--color-border); background: var(--color-card-bg); display:block; margin: 0.75rem 0 0.75rem 0;">

This work proposes and evaluates a real-time deep-learning approach for multi-class pest detection,
addressing class imbalance and intra-class variability.
The method is validated on the IP102 dataset and demonstrates improved precision and F1 scores over YOLO baselines.

- **DOI:** [https://doi.org/10.1109/IHTC61819.2024.10855066](https://doi.org/10.1109/IHTC61819.2024.10855066)
